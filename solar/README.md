# 太阳能蓝图：从 50×50 到祝融星

视频《异星工厂｜太阳能蓝图怎么摆？从50×50到祝融星》配套蓝图，Veros25。成片时长 14:43，按“定义问题与约束 → 小规模试排 → 50×50 → 大阵列 → 祝融星”展开。

## 下载与导入

- **推荐：[整合蓝图簿](solar-blueprint-book.txt)**，一次导入六套完整布局，默认选中新地星 50×50。
- **[直接打开完整字符串](https://raw.githubusercontent.com/flitting/factroio-bluePrint/main/solar/solar-blueprint-book.txt)**。
- 只需要其中一套时，下载下表中的单份 `.txt`。

打开纯文本或下载文件后，复制从 `0` 开始的完整字符串，在游戏中选择“导入字符串”。大图字符串较长，请使用 Raw／下载原文件，不要复制 GitHub 页面上截断的预览。

实测环境为 Factorio 2.1.24，普通品质；祝融星方案使用原生《太空时代》（Space Age）星球条件。新地星和祝融星的日照、昼夜周期不同，请按星球选图。

## 怎样开始建设和继续扩建

1. 在阵列外准备已有电网、通电的机器人平台、已部署的建造机器人和物流机器人、建材供货箱，以及有空位的回收端。
2. 将完整蓝图放在起始建造范围可达、且后续电网和物流网络能够接通的位置。50×50 按 50 格节距相接；大图按整张宏模块的尺寸相接。
3. 提供全部所需建材即可。无需拆分“启动蓝图”，也无需人为先只提供电线杆和机器人平台、再提供太阳能板。
4. 玩家继续放置相接的完整蓝图，机器人会随电网和平台的建成扩大施工范围。这里的扩建不代表蓝图会自行放置下一张。

**四张能否同时放下？** 新地星 50×50 与 1296×792 都已通过两个独立场景：先从空地建成一块、再扩到 2×2；以及在阵列内部为空地时，同一游戏 tick 放下四张相接的完整图。两者均可完成，无需等上一张全部建好再放下一张。两类测试都有阵列外的初始网络、供料、机器人和施工电力。

观察到的“先出现若干电线杆和平台，再逐渐填满太阳能板”来自真实施工记录。测试从一开始同时供应全部六类建材，并统一补货。这个结果不表示游戏保证每次都以完全相同的顺序施工。

## 绿箱、紫箱和回收物

- **绿箱（缓冲箱）**：保留蓝图中的请求设置。物流机器人从基地供货箱或存储箱向绿箱补货，建造机器人就近取料施工；绿箱不会接力给另一只绿箱补货。
- **紫箱（主动供货箱）**：箱内库存由物流机器人主动搬出。它不会吸入附近地上的物品，也不是所有拆除物的必经点。
- **树木、石头等拆除回收物**：由建造机器人送到可接收处。基地仍需有空位的黄箱或相应需求端；不能只把阵列里的箱子改成紫箱，就省略外部接收空间。
- 平台的机器人请求只调配网络中已经部署的机器人，不会把箱中的机器人自动变成已部署机器人。

## 大阵列为什么这样排

新地星大图以 18×22 小块拼成。甲块有 32 板、26 电池，乙块有 28 板、35 电池；用同一块 6×6 空间，在 4 块太阳能板与 9 个蓄电池之间交换，最后在整个电网上统一配平。不要单独无限复制甲块后仍按完整阵列的昼夜输出计算。

物流平台采用错位连接，保持橙色物流范围连通，并让绿色建造范围覆盖整片阵列。橙色范围不需要铺满每一块太阳能板。新地星 1296×792 从中间方案直接重复所需的 256 座平台减到 177 座，并一并减少箱子及连接设施占地。

祝融星大图沿用 72 列、36 排的宏观网格和 177 座平台布局，将小块改为 18×21，甲块为 34 板、17 电池，乙块为 30 板、26 电池，按祝融星原生 400% 日照与 90 秒昼夜重新配平。

50×50 的面积计数上限限定于视频中的固定配套配置：9 座变电站、1 座平台、2 个物流箱及相应储能要求。大图是目前已验证的较优方案；祝融星未完整重新搜索宏观尺寸，均不宣称全局最优。

祝融星未据此宣称通过“空地四张完整图同拍”验证。36×36、324×198 是视频展示的演进布局，不与两套最终方案共用同等范围的施工验证声明。

[validation.json](validation.json) 记录蓝图簿与单份导出的一致性、实体数量、配置摘要及文件校验值。单份蓝图直接从视频交付的蓝图簿提取；坐标、连线、箱子请求和平台设置均保留。

建造演示以 Factorio 真实建造事件和机器人位置记录驱动原版贴图动画回放，包含变速展示，并非直接屏幕录像。
