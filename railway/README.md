## 2026-11-25 修复说明

本次对原始“铁路路口”蓝图簿的全部11项进行 Factorio 2.1.25（build 88022）原生正常放置、幽灵实体复活和铁路连接组件审计。未更改列车寻路、铁路碰撞、信号规则或实体原型。

## 修复了什么

确认**涡轮式立交**与**涡轮式立交-2**各有4根地面直轨，组成两个各2根的中央短轨组件，与所有出入口的主网没有连接。它们是多余轨道，并非需要补建的转向线路。因此修复是删除这8个多余实体，保留全部有效通行轨道、坡道、支撑、信号与蓝图其他字段。

| 项目 | 涡轮式立交 | 涡轮式立交-2 |
|---|---:|---:|
| 原始实体数 | 542 | 500 |
| 修复后实体数 | 538 | 496 |
| 原始轨道连通组件 | 478 + 2 + 2 | 436 + 2 + 2 |
| 修复后轨道连通组件 | 478 | 436 |
| 原始/修复后信号区块数 | 39 → 40 | 39 → 40 |
| 原始/修复后轨段数 | 58 → 56 | 62 → 60 |
| 主体包围面积 | 不变 | 不变 |

几何交叉而没有通行连接的孤立轨道仍可能合并信号区块。因而“列车路线不变”不等于“拥堵下的行为不变”，本次不宣称仅删除孤立轨就提高吞吐量或保证无死锁。

`repair-diff.json` 逐项列出被删除实体的原始编号、原始坐标和方向。`patched-source-book.txt` 是可导入游戏的完整11项修复蓝图簿；另外两个 `*-repaired.txt` 是独立蓝图。完整蓝图簿保留原始名称、坐标、索引及其他元数据；其余9项和原始JSON完全相同。

## 「入口2」的两个组件

「入口2」单独审计时有58轨与27轨两个组件。其南侧分支在蓝图边界处结束，向外续建一根通常需要的主线直轨（原始坐标 `x=1273, y=385`）后两组件合为86轨的单一组件，正常建造通过。

这与中央孤立轨不同：它是边界处尚未包含下一节主线的道岔，可随主线延伸接通。因此没有擅自改动原簿中这一模块的边界接口。`entrance2-boundary-extension-probe.json` 用于复现边界接续诊断；另提供独立的 `entry2-complete.txt/json`（入口2·接续补全），已正常建造通过且只有一个86轨组件。它没有替换原簿中的入口2。

这里的连通与单列行驶验证不等于高负载死锁证明，也不等于稳定吞吐量测试。

最终对照：两张原图与两张修复图的48种OD单列行驶全部完成、零车体伤害事件；逐OD原生路径长度/代价/steps及行驶tick均一致。完整11项修复蓝图簿另经原生import成功，证据见 `book-import-validation.json`。
