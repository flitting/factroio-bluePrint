# 一条满黄带：铁板冶炼布局蓝图簿

视频《异星工厂：满带炼铁，最少要占多少格？》的配套蓝图。作者：Veros25 × GPT6。

按视频顺序收录 8 套布局：**682 → 561 → 546 → 525 → 477 → 450 → 442 → 435 格**。全部长边横向，使用石炉、普通电力机械臂、黄色传送带 / 地下传送带 / 分流器和小型电线杆。

## 整套导入

1. 打开 [iron-smelting-book.txt](iron-smelting-book.txt)，点击 GitHub 的 **Raw**，复制文件中从 `0` 开始的整条字符串。
2. 在《异星工厂》中使用 **导入字符串**，粘贴后确认。
3. 得到包含 8 套布局的蓝图簿，默认选中最后的 **435 格**布局。

[直接打开纯文本](https://raw.githubusercontent.com/flitting/factroio-bluePrint/main/smelting/iron-smelting-book.txt) · [可读 JSON](iron-smelting-book.json) · [单份蓝图目录](blueprints/) · [导出与导入核验](validation.json)

游戏使用 `.txt` 中的导入字符串即可，不需要自行处理 JSON。

全部 8 套蓝图已在原版引擎中完成“导出 → 导入 → 落地建造 → 再导出”核对：几何、方向、机械臂镜像、分流器设置和铜线保持一致。内部电线杆均为一个连通电网，全部机械臂由内部电线杆覆盖。检查结果见 [validation.json](validation.json)。

### 435 格的接口

以内部矩形的左上角为 `(0, 0)`，内部接口的中心位置为：

| 物料 | 中心坐标 | 流向 |
|---|---|---|
| 铁矿 | `(43.5, 0.5)` | 向下 |

## 使用要点

- 接入持续供应的铁矿、煤和足够电力，保持铁板出口畅通。蓝图簿不含发电装置或测试用无限物品源。
- 完整保留蓝图中的小型电线杆及其铜线、分流器设置和机械臂镜像。
- 477 与 450 都含 12 只镜像机械臂，用来把物品放到正确的一侧。
- 450 左侧两个分流器采用不同的输出优先级，导入后直接沿用。
- 435 中央朝右的分流器筛选 **铁板**，并将输出优先级设为 **右侧**。这项设置包含在蓝图中。
- 435 左下角朝上的空传送带用于维持邻接传送带的直带形态，**请保留**。地下口挡住来煤的一侧，另一侧通过，再与铁板分占传送带的两侧。
- 477 的末端包含有意不配对的地下入口，用于挡料和侧向汇入，不需要补成地下传送带对。

## 版本、来源与验证范围

蓝图以 **Factorio 2.1.24、原版 base、无研究加成**构建和导出，不需要内容模组。其他游戏版本未在本次工程中逐一验证。

- 682、561、546、525：使用视频已有蓝图的横向版本。
- 477：使用所给精确蓝图几何与已核对的运行配置。
- 450、442、435：使用最终视频制作中从示意图重建、恢复运行设置并在原版引擎中验证的版本；并非声称找回了原始蓝图字符串。

用于最终视频动画的新连续引擎记录如下。这些是有限时间窗口的运行记录：

| 布局 | 连续记录时长 | 窗口内输出铁板 |
|---|---:|---:|
| 477 | 100 秒 | 1500 块 |
| 450 | 110 秒 | 1649 块 |
| 442 | 100 秒 | 1500 块 |
| 435 | 130 秒 | 1950 块 |

450 的窗口计数为 1649 / 1650；短窗口的首尾库存与制作相位会影响计数，不将该记录写成一次新的长期满产证明。435 的原素材另有六工况一小时记录，但那些原始测试不能直接算作本次新重建蓝图的六次长测。

本蓝图簿提供视频的可导入布局；**435 格是这轮探索目前找到的最好结果，搜索尚未穷尽，全局最优性尚未证明。** 视频中的 440 格重排过程、理论候选，以及长机械臂分支不属于本蓝图簿。
